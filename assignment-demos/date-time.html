Current date and time

Question: Write a JavaScript program to display the current date and time in a message box.

Click the button to open a message box showing the current date and time.

View source code (HTML + JavaScript)
<p>Click the button to open a message box showing the current date and time.</p>
<button id="b">Show date and time</button>
<div id="out" class="msg"></div>

<script>
document.getElementById("b").addEventListener("click", function () {
  const now = new Date();
  const text = "Date: " + now.toDateString() + "\nTime: " + now.toLocaleTimeString();
  alert(text);   // message box
  const out = document.getElementById("out");
  out.className = "msg show ok";
  out.textContent = now.toString();
});
</script>
